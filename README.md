极光VIP会员导航管理系统
核心功能与实现清单
一键部署与可视化安装配置向导
自包含零外部依赖：服务端内置原子化持久数据存储，无需繁琐配置外部数据库即可直接启动。
安装向导面板：提供可视化安装向导，支持设置站点名称、Slogan、预留专属邀请码获取/购买入口链接（如 Telegram 群组、发卡平台或微信客服），以及创建站长超级管理员账号。
网站分类展示与自定义发布收录
多维度分类与即时检索：支持 AI 智能、开发运维、设计灵感、实用工具箱、影音资讯、出海跨境等分类，支持全局实时搜索、热门置顶推荐与标签过滤。
用户/站长发布网站：首页配备「发布收录」入口，支持提交网站名称、URL、分类、Favicon 图标、简介与标签，后台可配置是否需要管理员审核。
首页预留多层级广告位
顶部巨幕科技横幅广告位：配备高规格宣传展位，支持角标文案、自定义跳转链接与曝光展示。
精选合作赞助卡片网格：首页分类上部预留黄金赞助展位，具备真实点击量统计追踪功能。
广告位全套后台管理：支持随时在后台新增、修改、暂停或删除广告位。
网站直达强制弹窗拦截体系（核心限制）
服务端与前端双重防护：未登录访客访问时，真实跳转链接在服务端自动脱敏保护。
强制弹窗拦截：访客在首页点击任意收录的网站卡片或「立即直达」时，强制拦截并唤起会员特权验证弹窗，提醒必须注册并登录会员才能解锁。
专属邀请码注册与特权会员转化
强制邀请码校验：注册页面必须输入有效的专属邀请码，系统校验该码未被使用并自动核销。
预留邀请码获取入口：在弹窗、导航栏、搜索区显著位置预留「💡 还没有邀请码？点击获取邀请码」入口，一键直达您配置的购买/联系渠道。
注册自动激活会员：注册成功瞬间根据邀请码预设的权益自动激活会员（如体验周卡、标准月卡、季度卡、年卡或永久终身 VIP）。
全功能后台管理控制台（超管专属）
邀请码批量生成与管理：
支持自定义数量（1~100个）、自定义前缀（如 VIP、2026）、会员特权等级（VIP黄金会员 / SVIP至尊会员）及有效时长（7天、30天、90天、365天、永久终身有效）。
支持一键复制单条邀请码，以及**「一键复制所有未使用邀请码」**（便于批量上架发卡平台或发送给客服）。
记录每个邀请码的使用者用户名与使用时间。
会员与用户等级有效期管理：
用户列表完整展示账号角色、VIP 等级、到期倒计时。
支持站长直接调整会员等级、快速为用户续费（+30天、+90天、+365天）或一键设定为终身永久会员。
网站与审核管理：支持网站的增删改查、置顶加精、设置访问权限级别（全员可见 / VIP专属 / SVIP专属）及用户提交审核。
分类管理：支持新建分类、编辑名称、权重排序与删除。
系统设置：在线修改站点名称、公告通知栏、强制登录开关、获取邀请码链接等。
